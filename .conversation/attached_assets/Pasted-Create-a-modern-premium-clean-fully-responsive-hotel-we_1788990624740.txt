Create a modern, premium, clean, fully responsive hotel website for **MC-LEA Hotel & Suite**, located at:

**Mandella Estate, H18 11 Road, off SARS Road, Port Harcourt 500101, Rivers State, Nigeria.**

The website should feel like a professional boutique hotel website designed by an experienced hospitality brand and web design agency. It must look polished, trustworthy, elegant, fast, intuitive and visually appealing on desktop, tablet and mobile devices.

## 1. Overall Design Direction

Use a **modern minimalist luxury aesthetic**.

The design should communicate:

* Cleanliness
* Comfort
* Privacy
* Sophistication
* Peace and relaxation
* Professional hospitality
* Trust
* Modern Nigerian hospitality

Avoid a generic template appearance. The website should feel like a real premium hotel brand.

Use:

* Generous whitespace
* Large high-quality hotel and room photography
* Elegant typography
* Strong visual hierarchy
* Soft rounded corners where appropriate
* Subtle shadows
* Clean cards
* Sophisticated spacing
* Smooth transitions
* Subtle animations
* Premium-looking buttons
* Consistent alignment throughout the site

Use a refined color palette based around:

* Warm white / ivory
* Charcoal / deep black
* Soft beige
* Subtle muted gold as an accent

Do not overuse gold. The website should remain modern and understated.

Use an elegant serif font for major headings and a clean modern sans-serif font for body text and navigation.

Logo/brand:

**HOTEL & SUITE**

## 14. RESPONSIVE DESIGN

This is extremely important.

The website must be fully responsive across:

* Large desktop
* Desktop
* Laptop
* Tablet
* iPhone-sized screens
* Android-sized screens

Do not simply shrink the desktop design.

Create thoughtful mobile layouts.

On mobile:

* Navigation becomes a hamburger menu
* Buttons become appropriately sized touch targets
* Images scale correctly
* Text remains readable
* Booking forms stack vertically
* Cards become single-column where necessary
* No horizontal scrolling
* Gallery adapts elegantly
* Footer becomes vertically organized

Test the website at multiple viewport sizes.
